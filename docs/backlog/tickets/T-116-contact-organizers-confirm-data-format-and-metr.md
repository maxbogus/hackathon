# T-116: связаться с организаторами — уточнить формат данных, метрики, требования к команде

## Context

Хакатон Московского транспорта (25.09–03.10) — трек «ИИ-прогноз загрузки трамвайных маршрутов».
Бенефициары: Департамент транспорта Москвы, диспетчеры, пассажиры. Призовой фонд 500K/300K/200K RUB.

Без точных требований к формату данных, метрикам оценки и составу команды мы разрабатываем
вслепую. Это блокирует T-117 (RealSource), T-118 (адаптация), T-127/T-128 (user story для пассажира).

## Acceptance Criteria

- [ ] Получен официальный ответ от организаторов по email/Telegram
- [ ] Уточнены: формат исторических данных (parquet/csv/json), колонки, временной диапазон
- [ ] Уточнены: метрики оценки (RMSLE/MAPE/MAE/ETA error), способ валидации (holdout/public LB)
- [ ] Уточнены: требования к составу команды (3-5 человек — обязательно или рекомендация)
- [ ] Уточнены: формат очного финала (длительность питча, demo-оборудование, Q&A)
- [ ] Уточнены: возможен ли real-time API к текущим данным трамваев (GPS-треки, АСКП)
- [ ] Уточнены: условия использования данных (только для хакатона или можно публиковать метрики)
- [ ] Уточнены: лицензия решения (open-source обязательно? передача прав Департаменту?)
- [ ] Уточнены: API ключи для внешних сервисов (Яндекс.Пробки, OpenWeatherMap)
- [ ] Результат задокументирован в `docs/hackathon/requirements.md`
