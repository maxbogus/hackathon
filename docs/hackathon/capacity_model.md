# Capacity Model — пассажировместимость трамваев Москвы

> **T-128:** введена модель вместимости для расчёта `load_pct` (процент
> заполнения трамвая). Документ объясняет источники цифр, принятые допущения
> и стратегию валидации при появлении реальных данных от Департамента.

---

## 1. Зачем нужна модель вместимости

Боль пассажира: «Будет ли место в трамвае?» Голый `passenger_count` не даёт
ответа — 50 человек в «Львёнке» и 50 человек в «Витязе» означают совершенно
разный уровень заполненности. Перевод в `% заполнения` (load_pct) делает
прогноз понятным пассажиру и позволяет дать рекомендацию «садиться / ждать».

---

## 2. Источники цифр

Данные о реальной вместимости московских трамваев собирались из открытых
источников (официальный сайт «Московский транспорт», вики-страницы моделей,
паспорта производителей):

| Модель | Сегменты | Вместимость (сидя + стоя) | Источник |
|---|---|---|---|
| «Витязь-Москва» (71-931М) | 3 секции | ~150–200 pax | mos.ru / Wikipedia |
| «Львёнок-Москва» (ЛВС-2005 / 71-911) | 1 секция | ~80–100 pax | mos.ru |
| «Трамвай Т1 / Т2» (диаметры) | 5+ секций, длинные составы | ~250 pax | Планы запуска Т1/Т2, 2023 |

Цифры приблизительные: точная вместимость зависит от компоновки салона,
наличия багажных зон и т.п. Для MVP берём **средние** значения.

## 3. Константа `TRAM_CAPACITY`

Реализация: `apps/backend/app/forecast/load.py`.

```python
DEFAULT_TRAM_CAPACITY = 150  # fallback (Витязь-Москва single section)

TRAM_CAPACITY = MappingProxyType({
    1: 250,  # Т1 (diameter, long consist)
    2: 250,  # Т2 (diameter, long consist)
    # Все остальные маршруты → DEFAULT_TRAM_CAPACITY (150).
})
```

### Почему `MappingProxyType`, а не обычный dict

Immutable контейнер — гарантирует, что runtime код не изменит константу
по ошибке (`TRAM_CAPACITY[7] = 200` бросит `TypeError`). Защита от
side-effects в multi-thread FastAPI workers.

### Почему `forecast/load.py`, а не `config.py`

`app.config.Settings` (pydantic-settings) предназначен для **runtime knobs**,
которые читаются из ENV: `database_url`, `redis_url`, `cors_origins`,
`artifacts_dir`. Вместимость трамвая — это **доменная константа**, она не
меняется между dev / test / prod. Положение в `config.py` потребовало бы
оборачивать её в `pydantic.Field` с валидацией — overengineering для
хардкода, который всё равно читается один раз при импорте.

Решение зафиксировано: **D-012** в `docs/ledger/decisions.jsonl`.

## 4. Clipping policy: `[0, 150]`%

`load_pct` ограничен сверху **150%**, а не 100%. Зачем:

| Диапазон | Смысл | Цвет (UI) |
|---|---|---|
| 0% | Пустой трамвай | green |
| < 70% | Есть свободные места | green |
| 70–90% | Загрузка приемлемая, но «впритык» | yellow |
| 90–110% | Тесно, кто-то стоит | red |
| 110–150% | Перегрузка, реально критично | darkred |
| > 150% | Отбрасываем (модель ошиблась) | darkred |

150% — порог «нереалистично»: даже в час пик загрузка выше 1.5× номинала
говорит скорее о сбое датчика, чем о реальной ситуации. Clamping до этого
порога сохраняет информацию о перегрузе (UI может отрисовать darkred),
но не даёт диспетчеру увидеть абсурдные 300%.

## 5. Цветовая шкала — функция `load_color()`

```python
def load_color(load_pct: float) -> Literal["green", "yellow", "red", "darkred"]:
    if load_pct < 70:  return "green"
    if load_pct < 90:  return "yellow"
    if load_pct < 110: return "red"
    return "darkred"
```

Границы inclusive по верхнему краю: ровно 70% → «yellow», не «green».
Реализация: `apps/backend/app/forecast/load.py::load_color`.

## 6. Валидация при появлении реальных данных

Когда от Департамента поступят точные составы по маршрутам (см. запрос
в `docs/hackathon/requirements.md`):

1. **Сначала** — обновить `TRAM_CAPACITY` по их паспортам маршрутов.
2. **Потом** — переобучить калибровку (`make calibrate`) на реальных данных.
3. **Сравнить** `load_pct` на holdout-периоде до/после смены capacity.
4. **Если** расхождение > 5 pp на топ-10 маршрутах — добавить entry в
   `docs/ledger/findings.jsonl` (тег `capacity-calibration`).

На хакатоне у нас нет доступа к точным составам, поэтому используем
средние значения из открытых источников.
