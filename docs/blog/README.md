# docs/blog — серия постов «ИИ-скепсис»

> Черновики для внешнего блога. **Пока не публикуем**: в требованиях к организаторам
> вопрос «можно ли публиковать метрики и результаты» отмечен как незакрытый.
>
> Правило №1: любое число в посте обязано иметь строку-пруф в `00-FACTS.md`.
> Правило №2: посты обезличены — глоссарий подмен в `00-FACTS.md` §9.

## Состав

| Файл | Что это |
|---|---|
| `00-FACTS.md` | факт-база: ~70 утверждений «значение → пруф» (F-/D-ID, команда, файл) |
| `00-TZ-CONTRAST.md` | таблица «большое ТЗ (мы придумали) → маленькое ТЗ (что попросили) → факт» |
| `sources/organizer_dataset_readme.paraphrase.md` | пересказ правил задачи от заказчика (INTERNAL) |
| `stats.json` | машинные цифры; пересобирается `make blog-stats` |
| `01-big-tz-was-fanfic.md` | **Пост 1.** Как мы написали себе ТЗ на четыре роли — и оно оказалось фанфиком |
| `02-five-lines.md` | **Пост 2.** Пять строк, которые решали всё, — и три ошибки в их чтении |
| `03-standard-wins-broke.md` | **Пост 3.** Все приёмы, которые «рвали» другие соревнования, здесь сломались |
| `04-what-actually-worked.md` | **Пост 4.** Что реально подняло метрику: не модель, а знание предметной области |
| `05-one-person-vs-4-roles.md` | **Пост 5.** Один человек вместо четырёх ролей: честная цена ИИ |

## Порядок публикации и длина

| # | Объём | Тезис | Крючок в конце |
|---|---|---|---|
| 1 | ~1 400 знаков | ИИ ускоряет реализацию любой постановки, включая неверную | «как мы трижды неправильно прочитали пять строк» |
| 2 | ~1 500 знаков | В маленьком ТЗ ценна каждая запятая | «стандартные приёмы сломались» |
| 3 | ~1 300 знаков | Нет внешнего сигнала → «умные» приёмы учатся на утечках | «что сработало — не модель» |
| 4 | ~1 600 знаков | 8.84 из 10.7 пункта дали правила предметной области; у ИИ нет памяти без ledger | «сколько это стоило» |
| 5 | ~1 700 знаков | Масштабируется исполнение, а не суждение | — |

## Как поддерживать

```bash
make blog-stats     # пересобрать docs/blog/stats.json из репозитория
make blog-check     # stats + grep по постам (обезличивание)
make lint           # ruff + eslint + prettier
```

Если `make blog-check` падает — в посте появилась запрещённая строка
(имя, название площадки, дословная цитата, путь к данным). Список запретов —
`00-FACTS.md` §10.
